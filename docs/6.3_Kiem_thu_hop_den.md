# 6.3. Kiểm thử hộp đen (37 TC)

Phương pháp: **bảng quyết định (Decision Table)** kết hợp **phân vùng tương đương và giá trị biên**.
Mỗi chức năng gồm 3 bảng: (1) bảng điều kiện, (2) bảng quyết định, (3) bảng test case.

Quy ước giá trị: **T** = hợp lệ, **F** = không hợp lệ, **B** = bỏ trống. Dấu **-** = không xét.

> Ghi chú: cột "Kết quả mong đợi" lấy từ quy tắc trong code (`forms.py`, `models.py`, `auth_controller.py`, `chat_controller.py`). Cột "Kết quả thực tế / Đạt" cần điền sau khi chạy thử thật.
