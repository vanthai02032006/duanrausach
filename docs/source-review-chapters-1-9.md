## Kết luận áp dụng

Thiết kế sử dụng Django làm khung web sản xuất có xác thực và session, PostgreSQL làm nguồn dữ liệu nghiệp vụ, Gemini API làm mô hình tạo sinh, và `ai_service.py` làm tầng điều phối. Người dùng tương tác qua UI thay vì gọi API trực tiếp. Dữ liệu lấy từ database và kho tri thức được ghép vào prompt. Các khuyến nghị nông nghiệp cần được kiểm chứng; không tự động thay đổi dữ liệu nghiệp vụ.
